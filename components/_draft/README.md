# _draft — 아직 시스템에 없는 것

색인(`design-system.json`)에 없는 컴포넌트가 필요해졌을 때 **여기에만** 만든다.
`components/ui/` 에 새 파일을 추가하지 않는다.

## 왜 가르는가

시스템에 없는 것이 화면마다 하나씩 `components/ui/` 에 늘어나면, 그게 곧
시스템이 없는 상태다. 「없어서 만들었다」와 「시스템이 정한 것」이 같은 폴더에
섞이면 다음 사람은 둘을 구분할 수 없고, 결국 아무거나 가져다 쓴다.

여기 있는 것은 **후보**다. 두세 화면에서 반복해서 필요해지면 그때
`components/ui/` 로 승격하고, 그 김에 8상태(기본·호버·포커스·누름·비활성·로딩·
오류·성공)를 갖추고 `scripts/gen-components.mjs` 의 `DOC` 에 정의를 적는다.
한 화면에서만 쓰이고 끝났다면 지운다.

## 규칙

1. 파일 맨 위에 **왜 필요했는지 / 어느 화면에서 나왔는지** 한 줄.
2. 여기 있는 것을 `components/ui/` 에서 import 하지 않는다. 방향은 언제나
   화면 → `_draft` 다. 반대로 흐르면 임시가 정본을 물게 된다.
3. 색·간격은 그대로 토큰만 쓴다. 임시라고 리터럴을 허용하면 승격할 때 다시 짜야 한다.

## 형식

```tsx
/* 왜: 표 한 줄에서 여러 값을 한 번에 바꾸는 자리가 필요했다.
 * 어디서: /preview 목록 화면의 일괄 편집 줄. 2026-08-31 */
```

지금은 비어 있다. 비어 있는 것이 정상이다.
