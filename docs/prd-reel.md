# Reel — 말로 만드는 짧은 영상

## 1. 무엇을 푸는가

영상 생성 도구는 대개 «영상을 만들어 본 사람» 을 기준으로 만들어져 있다.
시드, 프레임 수, CFG, 모션 강도 — 처음 온 사람은 무엇을 건드려야 원하는 게
나오는지 알 수 없고, 잘못 건드려도 왜 이상해졌는지 모른다.

Reel 은 그 반대편을 잡는다. **한 줄 적으면 하나 나오고, 마음에 안 들면 말로
고친다.** 설정은 기본값이 이미 정답이고, 바꾸고 싶을 때만 눈에 띈다.

## 2. 누구를 위해

| 대상 | 상태 | 이 화면에서 성공은 |
| --- | --- | --- |
| 라이트 유저 (주 대상) | 영상 편집 경험 없음. 인스타 릴스·쇼츠는 매일 본다 | 처음 열고 3분 안에 쓸 만한 클립 하나를 얻는다 |
| 마케터 · 소상공인 | 소재가 급하다. 완성도보다 «오늘 올릴 것» | 문구를 조금 바꿔 가며 3~4개 뽑아 고른다 |
| 크리에이터 | 콘티 대신 빠른 시안 | 마음에 드는 컷을 골라 길이·비율만 손본다 |

**대상이 아닌 사람:** 정밀 제어가 필요한 영상 전문가. 그쪽은 시드와 카메라
경로를 열어 줘야 하는데, 그걸 열면 라이트 유저 화면이 망가진다. 다른 화면으로 나간다.

## 3. 원칙

1. **대화가 곧 작업 이력이다.** 별도의 «내 프로젝트» 목록을 만들지 않는다.
   위로 스크롤하면 오늘 만든 것이 순서대로 있다.
2. **설정은 세 개까지.** 길이 · 비율 · 분위기. 이 셋으로 설명되지 않는 것은
   문장으로 적게 한다. 슬라이더를 늘리는 대신 문장을 늘린다.
3. **기다림에는 이름을 붙인다.** «생성 중 63%» 대신 «장면을 그리는 중».
   무엇이 진행 중인지 알면 같은 40초도 짧게 느껴진다.
4. **실패는 다음 행동과 함께 온다.** «오류가 발생했습니다» 로 끝내지 않고,
   다시 시도 · 문구 고치기 중 하나를 바로 누를 수 있게 둔다.
5. **큰 글씨, 큰 과녁.** 이 화면의 밀도는 대시보드가 아니라 메신저에 맞춘다.

## 4. 범위

### 들어가는 것
- 한 줄 입력 → 클립 1개 생성 (기본 8초)
- 길이(4 · 8 · 12초) · 비율(세로 9:16 · 정사각 1:1 · 가로 16:9) · 분위기(6종)
- 이미지 1장 첨부 → 그 이미지로 시작하는 영상
- 결과 카드: 재생 · 다시 만들기 · 문구 고쳐 다시 · 내려받기
- 진행 상태 4단계: 문장 읽는 중 → 장면 잡는 중 → 그리는 중 → 다듬는 중
- 처음 온 사람용 예시 문장 3개
- 남은 생성 횟수 표시

### 나가는 것 (이번 화면 아님)
- 타임라인 편집, 컷 이어붙이기
- 음악 · 내레이션
- 팀 공유 · 권한
- 시드 고정, 카메라 경로, 모션 강도

## 5. 화면 구조

```
┌───────────────────────────────────────────────┐
│  Reel                        남은 횟수 · 계정  │  머리 (48px, 얇게)
├───────────────────────────────────────────────┤
│                                               │
│   [처음] 이렇게 적어 보세요 — 예시 카드 3장    │
│                                               │
│   나 ▸  «비 오는 도쿄 골목, 네온 반사»         │  오른쪽 정렬
│                                               │
│   ▸ 만드는 중 · 장면을 그리는 중  ▓▓▓▓░░ 68%   │
│                                               │
│   ▸ ┌─────────────┐                           │
│     │   클립      │  8초 · 9:16 · 시네마틱     │  왼쪽 정렬
│     │   ▶        │  [다시] [고쳐서 다시] [저장]│
│     └─────────────┘                           │
│                                               │
├───────────────────────────────────────────────┤
│  8초 ▾   9:16 ▾   시네마틱 ▾                   │  설정 (칩 3개)
│  ┌─────────────────────────────────────┐ ┌──┐ │
│  │ 어떤 장면을 만들까요?               │ │↑ │ │  입력 (2줄 높이)
│  └─────────────────────────────────────┘ └──┘ │
└───────────────────────────────────────────────┘
```

한 열. 최대 폭 46rem. 사이드바 없음 — 라이트 유저에게 «왼쪽에 뭐가 더 있다»
는 신호는 그 자체로 부담이다.

## 6. 상태

| 상태 | 화면 | 문구 |
| --- | --- | --- |
| 빈 상태 | 예시 카드 3장 | «무엇을 만들지 한 줄로 적어 보세요» |
| 입력 중 | 보내기 버튼 활성 | — |
| 생성 중 | 진행 막대 + 단계 이름 | «장면을 그리는 중 · 40초쯤 걸려요» |
| 완료 | 클립 카드 | «마음에 안 들면 다시 만들어도 횟수는 그대로예요» |
| 실패 | 카드 자리에 안내 | «장면을 만들지 못했어요. 문구를 조금 더 구체적으로 적으면 잘 나와요» + [다시] [고치기] |
| 한도 초과 | 입력 잠금 | «오늘 몫을 다 썼어요. 내일 다시 12번 생겨요» |

## 7. 성공 기준

- 처음 온 사람의 **첫 클립까지 3분 이내** (예시 문장을 눌러도 성공으로 친다)
- 첫 클립 이후 **두 번째 시도율 60% 이상** — 한 번 만들고 나가면 실패다
- 설정 칩을 한 번이라도 만지는 비율 30% 내외 —
  0% 면 안 보이는 것이고, 60% 를 넘으면 기본값이 틀린 것이다

## 8. 이 디자인 시스템과의 관계

새 컴포넌트를 만들지 않는다. 전부 `components/ui` 의 것을 쓰고, 이 화면이
입는 색·간격은 저장된 테마 **Test padding 2** 다. 즉 이 페이지는 기능 시안이자,
그 테마가 실제 제품에서 어떻게 보이는지 확인하는 자리이기도 하다.
