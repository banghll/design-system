# 씨네덱 (CineDeck) — 제품 요구사항

> 이 디자인 시스템으로 실제 제품을 하나 끝까지 만들어 본 기록.
> 시스템이 실제 화면을 감당하는지는 화면을 만들어 봐야만 알 수 있다.

---

## 1. 왜 만드는가

영화를 고르는 일은 정보가 부족해서가 아니라 **너무 많아서** 어렵다.
평점 사이트는 대부분 "전체 평균 8.4" 하나를 보여주고 끝난다. 그 숫자는
"나에게 맞는가" 에 답하지 못한다. 평균이 같은 두 영화도 분포가 다르면
완전히 다른 영화다 — 모두가 7점을 준 영화와, 절반이 10점 절반이 4점을 준
영화는 같은 영화가 아니다.

씨네덱은 **평균 대신 분포를, 점수 대신 기록을** 다룬다.

## 2. 사용자와 할 일 (Jobs)

| 누가 | 언제 | 무엇을 하려는가 |
| --- | --- | --- |
| 오늘 밤 볼 걸 찾는 사람 | 시간이 2시간 비었을 때 | 실패하지 않을 한 편을 고른다 |
| 고민 중인 사람 | 후보를 2~3개로 좁혔을 때 | 이게 나한테 맞는지 판단한다 |
| 기록하는 사람 | 다 보고 난 직후 | 점수와 한 줄을 남긴다 |
| 취향을 아는 사람 | 가끔 | 내가 뭘 좋아하는지 되돌아본다 |

이 넷이 그대로 네 화면이 된다.

## 3. 범위

### 만든다

| 화면 | 라우트 | 무엇을 해결하나 |
| --- | --- | --- |
| 발견 | `/movies` | "뭘 볼지 모르겠다" — 추천 한 편 + 지금 인기 + 큐레이션 |
| 탐색 | `/movies/browse` | "조건이 있다" — 장르·연도·평점·러닝타임으로 좁힌다 |
| 작품 | `/movies/title/[id]` | "이거 나한테 맞나" — 분포·태그·비슷한 작품 |
| 내 기록 | `/movies/me` | "내 취향이 뭐지" — 통계·평가 목록·위시리스트 |

### 만들지 않는다 (이번엔)

- 계정·로그인 — 로그인 블록은 이미 카탈로그에 5종 있다. 여기서 반복하지 않는다.
- 소셜 그래프(팔로우, 피드) — 다른 제품이다.
- 예매·결제 — 다른 제품이다.
- 관리자 화면 — 대시보드 블록이 이미 그 자리를 채운다.

## 4. 핵심 결정

### 4-1. 평점은 5점 척도, 0.5 단위

10점 척도는 6과 7의 차이를 설명할 수 없다. 5점 반 단위(10단계)는
"보통보다 조금 나음" 을 표현할 수 있으면서 고민 시간이 짧다.

### 4-2. 평균 옆에 분포를 반드시 붙인다

숫자 하나만으로는 판단할 수 없다는 것이 이 제품의 전제다.
작품 화면의 평점 영역은 **평균 · 분포 막대 · 참여 수** 세 가지가 한 벌이다.
셋 중 하나라도 빠지면 그 영역을 그리지 않는다.

### 4-3. 평가는 화면을 옮기지 않는다

다 본 직후의 사람은 참을성이 없다. 평가는 어느 화면에서든 다이얼로그로 뜨고,
점수만 남기고 닫아도 된다 — 한 줄평은 선택이다.

### 4-4. 봤음 / 위시리스트는 서로 배타적이지 않다

다시 볼 것도 있다. 두 상태를 독립된 토글로 둔다.

## 5. 상태 정의

시스템의 규칙("상태를 다 만들고 끝낸다")을 이 제품에서 실제로 지킨다.

| 화면 | 빈 상태 | 로딩 | 오류 |
| --- | --- | --- | --- |
| 발견 | 해당 없음(항상 콘텐츠 있음) | 카드 뼈대 | — |
| 탐색 | 조건에 맞는 작품 0건 → 조건 되돌리기 제공 | 그리드 뼈대 | — |
| 작품 | 평가 0건 → "첫 평가를 남겨보세요" | 히어로 + 본문 뼈대 | 없는 id → not-found |
| 내 기록 | 평가 0건 → 발견으로 유도 | 통계 뼈대 | — |

## 6. 시스템에서 무엇을 쓰는가

새로 만든 컴포넌트는 **없다**. 전부 카탈로그에 있는 것을 조립했다.

| 카탈로그 | 여기서 쓴 자리 |
| --- | --- |
| `sidebar` (앱 셸, inset 변형) | 전 화면 공통 셸 |
| `card` · `badge` · `avatar` | 작품 카드, 리뷰 |
| `chart` (recharts) | 평점 분포, 장르 분포, 월별 관람 |
| `table` | 내 기록의 평가 목록 |
| `dialog` | 평가 남기기 |
| `sheet` | 모바일 필터 |
| `slider` · `toggle-group` · `select` · `checkbox` | 탐색 필터 |
| `carousel` | 큐레이션 줄 |
| `command` | 전역 검색 (⌘K) |
| `tabs` · `separator` · `progress` · `skeleton` | 곳곳 |
| `empty` | 결과 0건, 기록 0건 |
| `sonner` | 평가 저장 알림 |
| `hover-card` · `tooltip` | 포스터 위 요약 |
| `breadcrumb` · `pagination` | 탐색 |
| `aspect-ratio` | 포스터 자리 고정 |

패턴 탭의 **빈 상태 · 지표 카드 · 목록 툴바 · 카드 개요** 를 그대로 가져다 썼다.

## 7. 데이터

작품 24편은 **가상의 작품**이다. 실재하는 영화에 없는 평점을 붙이면
그 자체가 사실이 아닌 기록이 되므로, 제목과 감독을 지어냈다.
포스터 자리에는 Unsplash 이미지를 쓴다 — 실제 포스터가 아님을 화면에서도
숨기지 않는다.

## 8. 성공 기준

이 제품이 아니라 **시스템**의 성공 기준이다.

1. 새 컴포넌트를 하나도 만들지 않고 네 화면을 완성할 수 있는가 → 목표
2. 프리셋을 바꾸면 이 제품도 같이 바뀌는가 → 리터럴 색을 한 번도 쓰지 않으면 참
3. 라이트·다크 양쪽에서 대비가 유지되는가
4. 한국어 · English 양쪽에서 레이아웃이 깨지지 않는가
